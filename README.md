# Fertilizer Usage & Crop Productivity Analysis

An exploratory data analysis project studying how **rainfall, fertilizer
and pesticide usage, seasons, and crop types** relate to agricultural
yield. Built as an EDAV course-end project, it applies the course
concepts to a crop-yield dataset and presents key patterns through
visualizations.

## What's inside

-   **Explore the data:** Load and inspect crop-yield records and
    summarize key fields.
-   **Clean and transform:** Check missing values, categorize rainfall,
    simplify seasons, and organize data using hierarchical indexes.
-   **Compare and summarize:** Calculate crop-wise yield and fertilizer
    statistics, and examine rainfall-related patterns.
-   **Study trends:** Compare annual yields and explore time-based
    summaries.
-   **Visualize insights:** Use bar, scatter, box, line, histogram, and
    facet plots to explore the data.

## Tools

`Python` · `NumPy` · `Pandas` · `Matplotlib` · `Seaborn`

## Run the project

1.  Keep `Fertilizer_Usage_and_Crop_Productivity_Analysis.ipynb` and
    `crop_yield.csv` together.

2.  Open the notebook in **Jupyter Notebook**, **JupyterLab**, or
    **Google Colab**.

3.  Install the required libraries if needed:

    ``` bash
    pip install numpy pandas matplotlib seaborn jupyter
    ```

4.  Update the CSV path in the data-loading cell to match your
    environment, then run the notebook cells in order.

## Visual highlights

The notebook includes: - Average yield across rainfall categories -
Fertilizer versus pesticide usage, with yield represented by color -
Yield distribution across seasons - Annual average yield trends - Rice,
wheat, and maize yield comparisons - Annual rainfall distribution and
fertilizer--yield patterns
